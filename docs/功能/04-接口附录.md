## 1. 使用说明

- 本表为机器可复算的注册清单；业务功能说明见 [02-功能清单](02-功能清单.md)。
- `鉴权` 列：`默认` 表示需要登录会话或 API Token；`Runner Token` 表示执行机器协议凭据；`内部 Token` 表示平台内部调用；`Token/会话` 表示 MCP 网关凭证。
- 匿名白名单（中央鉴权中间件放行）：`/api/health`、`/api/auth/setup`、`/api/auth/register`、`/api/auth/password`、`/api/auth/local`、`/api/auth/gongfeng/*`、`/api/auth/exchange`、`/api/capabilities`、`/api/openapi.yaml`；以 `internal/httpapi/auth*.go` 与会话中间件实现为准。
- 复算命令：`grep -rhoE '\.(GET|POST|PUT|PATCH|DELETE|Any)\("/[^"]*"' internal/httpapi --include='*.go' --exclude='*_test.go' | sort -u | wc -l`
