## 6. 能力边界与备注

- 渠道 Bot 支持企业微信、飞书、钉钉三种实现（`internal/botinteraction/channel_*.go`），通知渠道另有通用 provider。
- MCP 有两类进程：平台内 `POST /mcp` 网关与独立 stdio 进程 `cmd/agentflow-mcp`；两者共享 `PublicOperations()`。
- 预览既可由平台沙箱提供，也可由 Runner 回传内容；对应两套端点。
- 业务域报表只读聚合，写操作仅平台管理员与域管理员可用。
- 本次未统计：静态文件路由、`/api/openapi.yaml` 内容版本、WebSocket 消息类型；它们不是独立业务功能。
