# 03 领域术语表

> 文档编号：03

> 状态：术语基线 v1
> 证据基线：`develop` @ `6833a9fb`
> 适用范围：代码、数据库、接口文案、流程图、运营文档

## 1. 使用规则

- 同一概念只使用一个主术语；别名仅用于检索与兼容。
- 本表统一文档语义，不强制重命名代码、数据库字段或对外契约。
- 新增接口、表或领域对象时先补充本表，再更新流程图与功能清单。
- 对外文案与代码命名不一致时，以本表「代码映射」列为准记录差异。

## 4. 易混术语对照

| 术语组合 | 区别 | 推荐用法 |
| --- | --- | --- |
| 需求 / 执行机器任务 | 需求是业务交付项；RunnerTask 是平台内部执行单元 | 业务文档只用「需求」；协议文档用「执行机器任务」 |
| 运行 / 定时任务执行 | 运行由流程模板实例化；定时任务执行是 cron 触发记录 | 分开写，不简称「任务」 |
| 流程模板 / SOP / 工作流 | 同一对象；SOP 是对外名称，Workflow 是代码名 | 文档主用「流程模板（SOP）」，代码引用用 Workflow |
| 执行器 / 模型 CLI | 执行器是平台侧定义；CLI 是可执行程序 | 配置界面用「执行器」，安装语境用「CLI」 |
| 执行机器 / Worker | Runner 是独立节点；Worker 是平台进程角色 | 不把 Runner 称为「远程 worker」 |
| 沙箱 / 会话工作区 | 沙箱是容器环境；工作区是被挂载的代码目录 | 环境问题说「沙箱」，代码问题说「工作区」 |
| 助手会话 / 聊天房间 | 助手会话属于工作台；聊天房间属于渠道 Bot | UI 文案不混用 |
| 通知投递 / Bot 交互 | 投递是单向通知记录；交互是需要回执或确认的操作 | 重试语境用「投递」，确认语境用「交互」 |
| 预览 / 产物 | 预览是访问入口；产物是文件本身 | 下载说「产物」，打开说「预览」 |
| 交付 / MR | 交付是状态跟踪；MR 是具体合并请求 | 状态用「交付」，对象用「MR」 |
| 项目 / 协作空间 | 项目是配置与仓库单位；空间是需求讨论与产物集合 | 权限与仓库说「项目」，讨论说「空间」 |
| 角色 / 技能 / 规则 | 角色是 Agent 定义；技能是能力包；规则是约束文本 | 按对象类型使用，不统称「配置」 |

## 5. 状态口径

### 5.1 需求状态

`domain.Issue.Status` 的取值（代码注释与实现）：

| 值 | 含义 | 证据 |
| --- | --- | --- |
| `backlog` | 待排期 | `internal/domain/issue.go` |
| `todo` | 待开始 | 同上 |
| `in_progress` | 进行中 | 同上 |
| `in_review` | 待评审 | 同上 |
| `done` | 已完成 | 同上 |
| `closed` | 已关闭（可能由外部跟踪器关闭） | 同上 |
| `blocked` | 阻塞 | 同上 |
| `cancelled` | 已取消 | 同上 |

需求阶段的附属状态：`analyzing`、`in_progress`、`ready`、`needs_user`（`RequirementStage.Status`）。

### 5.2 运行状态

运行与节点使用字符串状态，代码中出现的取值：

| 值 | 含义 | 出现位置 |
| --- | --- | --- |
| `pending` | 待执行 | `internal/domain`、`internal/engine` |
| `running` | 执行中 | 同上 |
| `waiting` | 等待人工关口 | 同上 |
| `pending_input` | 等待补充信息 | 同上 |
| `succeeded` | 成功 | 同上 |
| `failed` | 失败 | 同上 |
| `cancelled` | 已取消 | 同上（另见少量历史拼写 `canceled`，以当前写入路径为准） |

未观察到统一的常量枚举；统计或筛选时请以路由/引擎写入值为准，不自行新增状态。

## 7. 现状问题与统一建议

| 问题 | 证据 | 建议口径 | 本次是否改代码 |
| --- | --- | --- | --- |
| 同一对象存在 SOP 与 Workflow 两种叫法 | README 与界面用 SOP，代码用 Workflow | 文档主用「流程模板（SOP）」，代码保持 Workflow | 否 |
| 运行状态为字符串字面量，无集中常量 | `internal/domain` 中 `"running"` 等散落 | 文档以本表为准；后续可集中常量，需单独评估 | 否 |
| 存在 `cancelled` 与 `canceled` 两种拼写 | 代码检索结果 | 以当前写入路径为准，历史值不新增 | 否 |
| 「任务」一词多义 | tasks 表、RunnerTask、定时任务 | 分别写「任务」「执行机器任务」「定时任务」 | 否 |

## 8. 维护规则

- 术语变化不触发流程图新版本；只有流程变化才新增流程版本。
- 代码/字段重命名必须单独评估接口兼容、数据迁移与调用方，不在术语任务中顺手改名。
- 新增表或路由后同步更新第 6 节映射与 [04-接口附录](04-接口附录.md)。
