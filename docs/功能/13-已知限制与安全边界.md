# 13 已知限制与安全边界

> 文档编号：13
> 项目：LoopForge
> 状态：当前代码快照
> 证据基线：`develop` @ `6833a9fb`
> 关联文档：[05-部署与运维](05-部署与运维.md)、[架构全景图](../架构全景图.md)

## 1. 部署边界

| 限制 | 影响 | 证据/说明 |
| --- | --- | --- |
| 平台容器挂载 Docker socket | 平台进程等价宿主机 root 权限 | `compose.yaml`；`docs/05-部署与运维.md` |
| 不是不可信多租户隔离 | 已登录用户可读实例内项目数据 | 官方部署文档「账号与访问边界」 |
| 默认允许自助注册 | 任何能访问登录页的人可注册普通账号 | `AGENTFLOW_ALLOW_SIGNUP` 默认 `true` |
| 默认监听所有网卡 | 暴露到网络即对内网可见 | `LOOPFORGE_BIND` 默认 `0.0.0.0` |
| Compose 不支持 native 沙箱 | 容器内无法创建 user/pid 命名空间 | 平台镜像不带 bwrap |

建议：只给可信成员账号；对外暴露前关闭注册、配置 HTTPS 反代并放通最小端口；管理员账号创建完成前限制来源 IP。

## 2. 凭据与密钥

| 限制 | 影响 | 处理 |
| --- | --- | --- |
| `AGENTFLOW_SESSION_SECRET` 变更 | 所有会话失效 | 跨重启与多副本保持一致 |
| `AGENTFLOW_CREDENTIAL_KEYS` 丢失 | 已保存的 Bot Secret 无法解密 | 与数据库备份一起保管；只能重填 |
| 密码哈希为 bcrypt | 本地账号密码不可逆 | 忘记密码用 `loopforge-account` 重置 |
| 平台共享 CodeBuddy Key | 管理员可见/替换 | 删除只影响共享 Key，个人 Key 不受影响 |

## 3. 数据与迁移

- 代码启动只做 AutoMigrate 增量 DDL；数据迁移与 seed 必须手动执行 `migrations/` SQL。
- 升级前必须备份数据库与二进制；Bot 回退到旧版本必须恢复备份（密文与租约协议不兼容）。
- 数据保留清理会作用于历史数据（正文默认 90 天、记录默认 180 天），升级前需确认保留设置。
- 删除会话会删除该会话开过的工作区；借用的 SOP 工作区不受影响。

## 4. 执行与沙箱

- 节点与运行状态使用字符串字面量，没有集中枚举；统计与筛选应以写入路径为准。
- 平台与执行机器必须同步升级；旧 Runner 对新工作区请求会拒绝。
- 沙箱内 Agent 会应用仓库自身配置（`AGENTS.md`、`.claude/settings.json`、`.mcp.json` 等），只应绑定可信仓库。
- 预览归档与会话有独立保留期；过期后需要重新归档。

## 5. 功能边界

| 限制 | 说明 |
| --- | --- |
| 外部跟踪平台 | 交付状态依赖外部 API，网络异常时状态滞后 |
| 知识库 | 检索由外部来源决定，平台不缓存正文 |
| 成本统计 | `reported` 权威、`estimated` 估算、`unknown` 未知，不应当作账单 |
| 最后一个管理员 | 代码未强制保留，需运维约束 |
| 需求五件套 | 当前仓库暂无按五件套登记的需求文档 |
