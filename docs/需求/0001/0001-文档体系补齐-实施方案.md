## 3. 链接处理

- 以原文件所在目录解析每个相对链接，按映射转换为新位置，再以新文件目录重算相对路径。
- 仅处理 Markdown 链接目标；`http(s)`、`mailto`、`tel`、`data`、纯锚点与代码围栏跳过。
- 合并后保留原章节标题文本，仅降低标题层级，避免锚点失效。
- 迁移完成后逐文件回写根 README、CONTRIBUTING、CHANGELOG、e2e 说明与 `AGENTS.md`。
