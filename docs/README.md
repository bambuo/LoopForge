## 1. 目录约定

`docs/` 固定五个位置：

| 位置 | 用途 |
| --- | --- |
| `README.md` | 本索引与目录约定 |
| `架构全景图.md` | 系统上下文、部署拓扑与运行时链路 |
| `需求/` | 一个需求一个目录，内含五件套与 `assets/`、`sql/` |
| `流程/` | 按功能点拆分的流程图、时序图与状态机，文件名带 `-vN` |
| `功能/` | 架构、功能清单、术语、规范、限制与迁移文档 |

保留例外（非文档资产或子项目手册，不迁入五目录）：

| 路径 | 原因 |
| --- | --- |
| `docs/api/` | Go 包 `apidocs`，`go:embed openapi.yaml`；移动会断编译 |
| `docs/assets/` | README 与文档引用的图片/HTML 资源 |
| `docs/local/` | Local 子项目手册，被 `local/README.md` 与根 README 引用 |

## 6. 索引与版本规则

- 功能与流程各自独立编号，不混用。
- 流程文档只有在流程变化时才新增 `-vN`；格式与措辞在当版修正，历史版本只读。
- 索引链接指向当前版本文件；新增或改名必须同步本表。
- 文档门禁（随仓库固化）：

```bash
node .skills/project-docs-bootstrap/scripts/check-docs.mjs \
  --docs docs --flow-dir 流程 \
  --require-flow-diagrams --require-status --require-evidence \
  --ignore api --ignore local --ignore assets
```
